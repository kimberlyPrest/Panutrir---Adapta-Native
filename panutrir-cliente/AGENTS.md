# Panutrir — Sistema Inteligente de Metas Comerciais

## Objetivo
Implementar a fase atual conforme as SPECs e tasks aprovadas, sem alterar o escopo por baixo.

## Stack
Supabase Auth, Postgres, RLS, Storage e migrations versionadas. Interface e runtime serão definidos no repositório de implementação.

## Regras
- Leia `CLAUDE.md`, `STATUS.md`, a fase e a SPEC antes de executar uma task.
- Use exclusivamente fixtures sintéticas na Fase 1; não solicite nem incorpore os CSVs reais.
- Execute RED, GREEN e REGRESSÃO definidos na SPEC.
- Não marque task concluída sem evidência objetiva.
- Não avance para outra fase sem liberação da consultora.
- Não publicar, migrar ou integrar fonte externa sem autorização explícita.
