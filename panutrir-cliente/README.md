# Panutrir — Adapta Native

Pasta operacional da Intranet Panutrir (Metas Comerciais + Logística).

- `01_projeto/`: objetivo, visão e regras do projeto.
- `02_reunioes/`: atas das reuniões de corte.
- `03_documentos/`: PRD, escopo, rastreabilidade, perguntas ao cliente e SPECs das fases futuras (`specs-programa/`).
- `04_fase-atual/`: fase aberta, SPECs e matriz de tasks do programa.
- `05_entregas/`: fases encerradas.
- `06_notas/`: metodologia oficial, emendas e aprendizado contínuo.

Fase ativa: 1 — Motor de meta Cliente × SKU com dados reais (EMENDA 02/2026).
