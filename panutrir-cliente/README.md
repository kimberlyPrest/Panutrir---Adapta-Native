# Panutrir — Adapta Native

Pasta operacional do projeto Sistema Inteligente de Metas Comerciais.

- `01_projeto/`: objetivo, visão e regras do projeto.
- `02_reunioes/`: atas das reuniões de corte.
- `03_documentos/`: PRD e escopo aprovados.
- `04_fase-atual/`: fase aberta, SPECs e tasks.
- `05_entregas/`: fases encerradas futuramente.
- `06_notas/`: notas operacionais e debug.

A Fase 1 usa Supabase e exclusivamente fixtures sintéticas.
